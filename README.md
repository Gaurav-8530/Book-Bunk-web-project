# 🏠 BooknBunk

BooknBunk is a full-stack web application where users can explore listings, add their own listings, upload images, and leave reviews. It is built using Node.js, Express, MongoDB, and Bootstrap.

---

## 🚀 Features

- 🔍 Explore all listings
- ➕ Add new listings with image upload
- ✏️ Edit and delete your listings
- 🔐 User authentication (Signup/Login/Logout)
- 💬 Add and delete reviews
- ⭐ Rating system
- ☁️ Image upload using Cloudinary
- 📱 Fully responsive UI using Bootstrap

---

## 🛠️ Tech Stack

- **Frontend:** HTML, EJS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Image Storage:** Cloudinary
- **Authentication:** Passport.js
- **Others:** Multer, dotenv, connect-flash
